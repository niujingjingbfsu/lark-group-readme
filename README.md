# Seraphina 群协作小技能

给团队同学：以下两件事可以**直接和 Seraphina 说一句话**就让她干，不用自己跳到飞书后台。

## 1. 拉个群 · `lark-create-group`

**怎么说**

> Sera，拉一个群叫 "Send as User 方案讨论"，把张三、李四加进来，主题是产品方案产出。

**她会做**

1. 把名字解析成飞书账号（如果有重名会问你是哪一个）
2. 建群、拉人、给群一句话简介
3. 把新群的 `chat_id` 和深链接回给你，点一下就跳进去

**注意**

- 人多（5 个以上）或跨租户的时候她会先发草稿让你确认再建
- 你自己不用列在成员里，建群人默认在群

---

## 2. 改群公告 · `lark-group-announcement`

**怎么说**（在那个群里 @ 她，或者在私聊里告诉她是哪个群）

> Sera，把我们群里这两天聊的 XX 方案沉淀到群公告里。

> Sera，群公告里"沉淀产出"和"当前进展"调换一下顺序。

> Sera，群公告加一行：本周决策 XX。

**她会做**

1. 拉群里最近的消息和被引用的文档，看大家聊了啥
2. 整理成「讨论主题 / 沉淀产出 / 当前进展」三段（或你指定的结构）
3. **先发一张草稿卡片**给你预览，**带「✅ 发布到群公告」按钮**
4. 你点确认她才真正写进群公告；公告对群里所有人可见，所以一定走这一步

**注意**

- 第一次用某个群，需要群里有 Seraphina（Bot 名字），且 bot 应用要开 `im:chat.announcement:read` / `im:chat.announcement` 两个权限
- 改公告时她会优先用"挪 block"的方式，而不是删了重建——保留评论/附件的绑定

---

## 3. 每天一次自动提醒（可选）

如果你想让 Seraphina 每天**自动看一眼某个群**，判断有没有需要更新公告的内容：

> Sera，请把咱群加入每日公告检查。

她会在群里**每天 9 点左右**发一张卡片，列出昨天新增的链接 / 讨论焦点 / 关键决策，问你"要不要把这些纳入群公告"。

- 点「看草稿」→ 她会按上面的流程出一份草稿让你确认
- 不点 → 卡片自己就过了，不会主动改任何东西
- 想取消：**"取消每日检查"**

> 公告**永远不会自动发布**——必须你点确认。这是设计上的红线。

---

## 出错了？

- 「`[99991672] Permission denied`」 → 应用权限没开。让 Bot 应用的管理员去开 `im:chat.announcement:read` / `im:chat.announcement`，发版后重试。
- 「`[232097] Unable to operate docx type chat announcement`」 → 内部错误，告诉 Seraphina 一声她会换条路走。
- 群公告改完没看到变化 → 飞书客户端缓存，下拉刷新一下群信息页。
